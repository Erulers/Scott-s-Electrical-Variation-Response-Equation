Formula;

$$
\Omega_s(t)=
\sqrt{
\Omega_0^2+
\frac{\beta}{T}
\int_0^t
e^{-\lambda(t-\tau)}
\left(\frac{dV(\tau)}{d\tau}\right)^2
\,d\tau
}
$$
